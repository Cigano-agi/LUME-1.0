# Telas e critérios observáveis

| Tela | Conteúdo e ação |
|---|---|
| Agora | Precisa de você / Lume está cuidando / O que mudou;3itens iniciais cada e expansão; pessoa/assunto/acontecimento/consequência; abrir assunto é ação principal |
| Memória | Busca natural textual disponível, filtros pessoa/assunto/período/fonte; resposta só se sustentada; trechos/autoria/data/origem; áudio mostra transcrição disponível e documento conteúdo processado; lacunas explícitas |
| Detalhe | Painel lateral contexto/combinados/responsáveis/próximos passos/fontes/histórico; corrigir vínculo/classificação, preparar resposta/acompanhar via controles existentes; fechar preserva posição |
| Comercial | Lista priorizada de oportunidades/retornos; confirmado e inferido separados; Kanban opcional sem arrastar obrigatório; temperatura nunca probabilidade |
| Entregas | Cliente/projeto/compromisso/dependência/próxima verificação; informado/verificado/enviado/aceito distintos; prazo ausente permanece ausente |
| Pessoas | Nomes persistidos, busca/contexto; acompanhar/preparar/atender separados; pausa temporária/retomada visíveis; grupos e categorias proibidas sem envio habilitável |
| Conversa/fonte | Timeline autoria/data/transcrição/documento/eventos, busca abre trecho; vínculos de assunto por trecho, nunca todo histórico automaticamente |
| Relações | Memória→mapa2D e lista equivalente; apenas vínculos existentes ou sugestões rotuladas; seleção abre detalhe |
| Ajustes | Conexões; Atendimento e limites; Aparência e companhia; Dados e diagnóstico. ChatGPT nome correto, avançado expandível, feedback contextual e aqui |

Todas seguem matriz de FLUXOS.md. Manter telas auxiliares funcionais, legibilidade/fontes e ações existentes. Busca sempre acessível, Perguntar/Comandos/Mapa removidos da navegação principal; acesso contextual preservado.
